# Приёмочный набор: реальные задания «Бегущего города» в Тбилиси

Набор проверяет, что поиск Quchebi (пакет данных + DSL) находит ответы на настоящие загадки
прошлых игр. Источник — опубликованные разборы маршрутов на runcity.org
(`/ru/events/<событие>/routes/all/`): адреса КП, загадки и отгадки.

**Авторское право.** Тексты загадок здесь не публикуются. В JSON — только пересказ своими словами
(не длиннее 25 слов), короткие факты («раньше называлась ул. Крылова») и адрес ответа. Сырые
страницы и извлечённые тексты лежат в `data/raw/runcity/` (не в git). Тест
`test_runcity_tasks.py` проверяет, что ни пересказ, ни факты не повторяют исходный текст
фрагментом из 6 слов и длиннее.

## Файлы

| файл | что это |
|---|---|
| `runcity_tasks.json` | 138 загадок с известным ответом (источник правды для приёмки) |
| `runcity_addresses.json` | 183 латинских написания адресов с карточек обычных КП: поиск по латинице |
| `run_acceptance.mjs` | прогон всех запросов по пакету и модулям приложения, сводка и вердикт |
| `test_runcity_tasks.py` | pytest: схема, словарь типов, ключи DSL, проверка на дословные совпадения |
| `tools/fetch_runcity.py` | вежливая докачка страниц маршрутов (пауза 4 с) в `data/raw/runcity/<событие>/` |
| `tools/extract_runcity.py` | разбор страниц в `data/raw/runcity/extracted.json`, только КП в границах Тбилиси |
| `tools/build_tasks.py` | курированные записи (в коде) → `runcity_tasks.json`, с проверками |
| `tools/build_addresses.py` | адреса КП → улица OSM по сходству имени и расстоянию → `runcity_addresses.json` |

## Запуск

```
node tests/acceptance/run_acceptance.mjs
```

Опции: `--pack DIR` (по умолчанию `app/public/data`), `--only <id или тип>` (например
`--only tbilisi2025` или `--only old_name`), `-v` (все запросы с числом результатов и местом
ответа), `--json report.json` (машиночитаемый отчёт), `--no-addresses`, `--strict` (код выхода 1,
если метрика не выполнена). Если пакета или модулей `app/src/search/index.js`,
`app/src/dsl/parser.js`, `app/src/dsl/eval.js` ещё нет или они не загружаются, скрипт сообщает
об этом и выходит с кодом 0. Журнал — `logs/acceptance_js.log`.

Проверка самого набора: `uv run pytest tests/acceptance`.

Пересборка набора (нужны сырые страницы и кэш Overpass в `data/raw/`):

```
uv run python tests/acceptance/tools/fetch_runcity.py
uv run python tests/acceptance/tools/extract_runcity.py
uv run python tests/acceptance/tools/build_tasks.py
uv run python tests/acceptance/tools/build_addresses.py
```

## Как устроена запись

```json
{
 "id": "tbilisi2025-93", "event": "tbilisi2025", "kp": 93, "kp_dupes": [],
 "kp_point": [41.708167, 44.839884],
 "category": "Сфинкс", "categories": ["Сфинкс"],
 "task_type": ["eponym_occupation", "house_number"], "needs_media": "audio",
 "summary_ru": "пересказ своими словами, до 25 слов",
 "answer": {"street_ru": "улица Темура Кевхишвили", "street_ka": "თემურ ქევხიშვილის ქუჩა",
            "alt_ka": [], "kind": "street", "house": "24", "corner_with": null,
            "raw_address": "Ул. Темура Кевхишвили, д. 24"},
 "facts": ["Темур Кевхишвили — солист и хормейстер", "..."],
 "solvable_by_search": true, "unsolvable_reason": null,
 "dsl_keys": ["кто", "дом", "текст"],
 "queries": [{"q": "кто:хормейстер дом:24", "mode": "facts",
              "expects": "answer street in results", "max_results_ok": 30}]
}
```

- `category` — самая «строгая» категория из тех, где была загадка (Сфинкс > Лев > Грифон);
  для квестов и «Звонка другу» — `неизвестно`. Полный список — в `categories`.
- `task_type` — одно или несколько из: `eponym_occupation`, `old_name`, `rename_chain`,
  `house_number`, `corner`, `direction`, `letter_pattern`, `number_in_name`, `latin_sign`,
  `square_or_park`, `other`.
- `answer.street_ka` и `alt_ka` — точные грузинские имена (по OSM на 23/10/2026); ответ ищется
  по скелету этих имён, а также старых имён объекта (`old[].ka`) — переименованная улица тоже
  засчитывается. Если `street_ka` нет — по скелету основы `street_ru` и типу `kind`.
- `queries[].mode`: `facts` — запрос только по фактам из загадки (профессия тёзки, старое имя,
  шаблон букв), без имени ответа; `name` — игрок уже вывел имя (ребус, шарада, анаграмма) и
  ищет улицу и дом. Запросы строго по `docs/dsl.md`, без зоны.
- `solvable_by_search: false` — ответ не улица из пакета: заведение или памятник (POI), место
  по старой карте или фото, железнодорожный пункт. Причина — в `unsolvable_reason`. Их запросы
  (если есть) прогоняются для информации.

## Метрика приёмки

Задание решено, если хотя бы один его запрос вернул ответную улицу и она стоит в первых
`max_results_ok` строках результата (30 для запросов по фактам, 10 для запросов по имени).
**Приёмка пройдена, если решено не меньше 90% заданий с `solvable_by_search = true`.**
Отдельно печатается, сколько решено только запросами `facts`: это мера качества обогащения
(эпонимы, старые названия, шаблоны).

Причины провала в отчёте: `parse` (ошибка разбора), `eval` (ошибка значения или исключение),
`no_answer_in_pack` (ответной улицы нет в пакете — пробел данных; печатаются ближайшие к КП
объекты), `no_house` (у ответной улицы нет нужного дома), `not_found` (ответа нет в
результатах), `rank` (ответ есть, но ниже допустимого места).
